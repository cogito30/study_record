# Part 03. 논리적 설계

## Chaptere 07. 관계 데이터 모델
- 관계 데이터 모델(relational data model): DB를 2차원 테이블, 즉 relation의 집합으로 모델링하는 논리적 데이터 구조
- 행(row)는 record에 해당하고 열(column)은 field/item에 해당한다.
- relation은 행과 열의 형태로 이루어진 테이블을 지칭한다
---
(관계 데이터 모델의 특징)
- 개체와 관계가 모두 2차원 테이블, relation으로 표현된다
- ER 모델을 관계 데이터 모델로 변환하는 것은 쉽다.
---
(relation과 table의 차이점)
- relation은 다소 추상적인 개념이고 테이블은 relation을 표현하는 구체적인 표현 방법이다.
- 하나의 릴레이션은 여러 형태의 테이블로 표현 가능하다
- 테이블은 중복되는 행을 허용하지만 릴레이션은 수학의 집합 개념을 기초로 하므로 중복되는 행을 허용하지 않는다.
---
(관계 데이터 모델 관련 용어)
- tuple(행)/attribute(열)
- domain(속성이 취하는 모든 값의 집합)
- cardinality(튜플의 수)/degree(속성의 수)
- relation/relation schema/relation instance
- key(튜플을 유일하게 식별할 수 있는 속성들의 집합)
---
- 키 속성은 현재데이터만 고려해서 결정하면 안된다.
