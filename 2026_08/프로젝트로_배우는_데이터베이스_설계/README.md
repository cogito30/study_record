#### Chapter 01. 데이터베이스 개요
- 용어 정리: data, information, database, DBMS
- 데이터베이스 3단계 구조: 외부 스키마/개념 스키마/내부 스키마

- 데이터베이스 구축 6단계: 요구 수집 및 분석 > 개념적 설계 > DBMS 선정 > 논리적 설계 > 물리적 설계 > 구현 및 테스트
