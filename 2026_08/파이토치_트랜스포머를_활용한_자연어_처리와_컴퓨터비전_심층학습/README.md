# 파이토치 트랜스포머를 활용한 자연어 처리와 컴퓨터비전 심층학습	

## Part2. 자연어처리

#### ch05. 토큰화
- National Language: 사람들이 쓰는 언어 활동을 위해 자연히 만들어진 언어
- National Langauge Processing(NLP): 컴퓨터가 인간의 언어를 이해하고 해석 및 생성하기 위한 기술
- Corpus: 자연어 모델을 훈련하고 평가하는 데 사용되는 대규모의 자연어
- Token: 개별 단어나 문장 부호와 같은 텍스트를 의미. corpus보다 더 작은 단위
- Tokenization: 컴퓨터가 자연어를 이해할 수 있게 token으로 나누는 과정
- Tokenizer: 텍스트 문자열을 token으로 나누는 알고리즘 또는 소프트웨어

- Curse of Dimensionality: 학습 데이터의 차원이 증가할수록 학습에 필요한 데이터가 증가하거나 모델의 성능이 저하되는 현상
- Sparse vector: 벡터 값이 거의 모두 0의 값을 가지는 vector

(자연어 처리 모델 개발시 고려사항)
- Ambiguity: 언어는 단어와 구가 사용되는 맥락에 따라 여러 의미를 갖게 되어 모호한 경우가 많아 다양한 의미를 이해하고 명확하게 구분해야한다.
- Variability: 언어는 다양한 사투리, 강세, 신조어, 작문 스타일로 인해 가변적이다.
- Structure: 문장이나 구의 의미를 이해할 때 구문을 파악하여 의미를 해석한다.

(Tokenizer 구축 방벙)
- 공백 분할
- 정규표현식 사용
- Vocabulary 사용
- Machine Learning 활용
 
- Word Tokenization: 자연어 처리의 전처리 작업 중 하나로 텍스트 데이터를 의미 있는 단위인 단어로 분리하는 작업. 띄어쓰기, 문장 부호, 대소문자 드으이 특정 구분자를 활용해 토큰화 수행
- Character Tokenization: 글자 단위로 문장을 나누는 방식. 비교적 작은 단어 사전 구축
- Jamo(자모): 언어의 문자 체계에서 의미상 구별할 수 있는 가장 작은 단위. a, b, c, ㄱ, ㄴ, ㅏ, ㅑ.
- Morpheme Tokenization: 텍스트를 형태소 단위로 나누는 토큰화 방법. 언어의 문법과 구조를 고려해 단어를 분리하고 이를 의미있는 단위로 분류하는 작업
- Morpheme(형태소): 실제로 의미를 가지고 있는 최소의 단위
- Free Morpheme(자립 형태소): 스스로 의미를 가진 형태소
- Bound Morpheme(의존 형태소): 스스로 의미를 갖지 못하고 다른 형태소와 조합되어 사용되는 형태소
- Morpheme Vocabulary: 각 단어의 형태소 정보를 포함하는 어휘 사전. 단어가 어떤 형태소들의 조합으로 이루어져 있는지에 대한 정보를 포함. 각 형태소가 어떤 품사에 속하는지와 해당 품사의 뜻 등의 정보도 제공
- POS Tagging(품사 태깅): 텍스트 데이터를 형태소 분석하여 각 형태소에 해당하는 POS(Part Of Speech)를 태깅하는 작업. 이를 통해 문맥 고려 가능

- Subword Tokenization: 하나의 단어가 빈번하게 사용되는 Subword의 조합으로 나누어 토큰화하는 방법
- 하위 단어 토큰화 방법: BPE, Wordpiece, Unigram, BBPE
- BPE(Byte Pair Encoding, Digram Coding): 하위 단어 토큰화의 한 종류. 텍스트 데이터에서 가장 빈번하게 등장하는 글자 쌍의 조랍을 찾아 부호화하는 압축 알고리즘.
  - 입력 데이터에서 가장 많이 등장한 글자의 빈도수를 측정하고, 가장 빈도수가 높은 글자 쌍을 탐색
  - 기존 말뭉치에 등장하지 않았던 단어가 입력되더라도 OOV로 처리되지 않고 토큰화 가능
- Wordpiece: BPE과 유사한 방법으로 학습되지만 빈도 기반이 아닌 확률 기반으로 글자 쌍을 병합
  - 모델이 새로운 하위 단어를 생성할 때 이전 하위 단어와 함께 나타날 확률을 계산해 가장 높은 확률을 가진 하위 단어를 선택
  - 이렇게 선택된 하위 단어는 이후에 더 높은 확률로 선택될 가능서잉 높으며, 이를 통해 모델이 좀 더 정확한 하위 단어로 분리
  - 각 글자 쌍에 대한 점수(Score) = f(x, y) / (f(x), f(y))
  - f(frequency), x,y(병합하려는 하위 단어)
- Unigram: 크기가 큰 어휘사전에서 덜 필요한 토큰을 제거하며 학습
- BBPE(Byte-level Byte-Pair-Encoding): 유니코드 단위가 아닌 바이트 단위에서 토큰화

#### ch06. 임베딩
- Text Vectorization: 텍스트를 숫자로 변환하는 방법
  - One-Hot Encoding: 문서에 등장하는 각 단어를 고유한 색인 값으로 매칭한 후, 해당 색인 위치를 1로 표시하고 나머지 위치는 모두 0으로 표시하는 방식
  - Count Vectorization: 문서에서 단어의 빈도수를 세어 해당 단어의 빈도를 벡터로 표현하는 방식
 
 - 원-핫 인코딩의 경우 토큰의 개수만큼의 벡터 차원을 가져 컴퓨터 비용의 증가와 차원의 저주 문제가 생길 수 있다.
 - 또한 텍스트의 벡터가 입력 텍스트의 의미를 내포하고 있지 않아 두 문장이 의미적으로 유사하다고 해도 벡터가 유사하게 나타나지 않을 수 있다.

- Word Embedding: 단어의 의미를 학습해 표현하는 방법
  - Word2Vec, fastText
  - 워드 임베딩은 단어를 고정된 길이의 실수 벡터로 표현하는 방법
  - 단어의 의미를 벡터 공간에서 다른 단어와의 상대적 위치로 표현해 단어 간의 관계를 추론

 - Dynamic Embedding: 인공신경망을 활용하는 기법
   - 워드 임베딩은 고정된 임베딩을 학습하기 때문에 다의어나 문맥 정보를 다루기 어렵다는 단점이 있어 인공 신경망을 활용한 방법
  
 - Language Model: 입력된 문장으로 각 문장을 생성할 수 있는 확률을 계산하는 모델. 주어진 문장을 바탕으로 문맥을 이해하고 문장 구성에 대한 예측을 수행
 
 - Autoregressive Language Model: 입력된 문장들의 조건부 확률을 이용해 다음에 올 단어를 예측.
  - 언어 모델에서 조건부 확률은 이전 단어들의 시퀀스가 주어졌을 때, 다음 단어의 활률을 계산하는 것을 의미
  - 이전에 등장한 모든 토큰의 정보를 고려하며, 문장의 문맥 정보를 파악하여 다음 단어를 생성
  - Chain rule for conditional probability(조건부 확률의 연쇄법칙): 하나의 사건이 일어날 확률을 다른 사건들의 조건부 확률을 이용해 계산하는 방식
  - 이전 단어들의 시퀀스가 주어졌을 때, 다음에 등장하는 단어의 확률을 이전 단어들의 조건부 확률을 이용해 계산
  - 모델의 출력값이 모델의 입력값으로 사용되는 특징을 가진다

- Statical Language Model(통계적 언어 모델): 언어의 통계적 구조를 이용해 문장이나 단어의 시퀀스를 생성하거나 분석. 시퀀스에 대한 확률 분포를 추정해 문장의 문맥을 파악해 다음에 등장할 단어의 확률을 예측
  - 통계적 언어 모델은 마르코프 체인을 이용해 구현
  - Markov Chain: 빈도 기반의 조건부 확률 모델 중 하나로 잊전 상태와 현재 상태 간의 전이 확률을 이용해 다음 상태를 예측
  - Data sparsity 문제: 관측한 적이 없는 데이터를 예측하지 못하는 문제
  - 대규모 자연어 데이터를 처리하는 데 효과적
 
- N-gram: 기초적인 통계적 언어 모델
  - N-gram은 텍스트에서 N개의 연속딘 단어 시퀀스를 하나의 단위로 취급하여 특정 단어 시퀀스가 등장할 확률을 추정
  - 연속된 N개의 단어를 하나의 단위로 취급하여 추론하는 모델
  - N이 1이면 Unigram, 2이면 Bigram, 3이면 Trigram으로 부른다
  - N-gram은 N-1개의 토큰만을 고려해 확률을 계산한다
  - 작은 규모의 데이터세트에서 연속된 문자열 패턴을 분석하는 데 큰 효과를 보인다
  - 관용적 표현 분석에 사용
  - 단어의 순서가 중요한 자연어 처리 작업 및 문자열 패턴 분석에 활용
  
- TF-IDF
  - TF-IDF(Term Frequency-Inverse Document Frequency): 텍스트 문서에서 특정 단어의 중요도를 계산하는 방법
  - 문서 내에서 단어의 중요도를 평가하는 데 사용되는 통계적인 가중치를 의미
  - TF-IDF는 BoW에 가중치를 부여하는 방법
  - BoW(Bag-of-Words)는 문서나 문장을 단어의 집합으로 표현하는 방법. 문서나 문장에 등장하는 단어의 중복을 허용해 빈도를 기록
  - BoW를 이용해 벡터화하는 경우 모든 단어는 동일한 가중치를 갖는다
  - TF(Term Frequency): 문서 내에서 특정 단어의 빈도수를 나타내는 값. 문서의 길이가 길어질수록 해당 단어의 TF값이 높아질 수 있다
  - DF(Document Frequency): 한 단어가 얼마나 많은 문서에 나타나는지를 의미. 단어가 몇 개의 문서에서 등장하는지 계산
  - IDF(Inverse DF): 전체 문서 수를 문서 빈도로 나눈 다음 로그를 취한 값. 문서 내에서 특정 단어가 얼마나 중요한지 표현. 단어의 빈도수가 적을수록 IDF값이 증가.(분모가 0이 되는 것을 방지하기 위해 1을 더함)
  - TF-IDF는 TFxIDF로 사용
  - 문서 내에 단어가 자주 등장하지만 전체 문서 내에서 해당 단어가 적게 등장하면 TF-IDF 증가
  - 빈도 기반 벡터화는 문장의 문서나 문맥을 고려하지 않는다

- Word2Vec
  - distributional hypothesis(분포 가설)을 기반으로 개발
  - 분포 가설: 같은 문맥에서 함께 자주 나타나는 단어들은 서로 유사한 의미를 가질 가능성이 높다는 가정. 단어 간의 동시 발생 확률 분포를 이용해 단어 간의 유사성을 측정



## Part3. 컴퓨터비전
